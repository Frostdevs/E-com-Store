🛒 E-Commerce Website

A fully responsive and modern e-commerce web application that allows users to browse products, add them to cart, and make secure purchases. Built to demonstrate real-world online shopping features with a strong focus on functionality, clean design, and performance.

🌟 Features

🏠 Homepage: Displays featured and trending products.

🔍 Product Search & Filter: Easily find items by name, category, or price range.

🛍️ Product Details: View detailed product descriptions, ratings, and reviews.

🛒 Shopping Cart: Add, remove, or adjust product quantities before checkout.
